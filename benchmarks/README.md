# Benchmarks

This directory contains public-safe benchmark case definitions and, later,
machine-readable benchmark result examples.

Do not store generated bulk audio, private voice samples, licensed corpora, or
identity-sensitive artifacts here without a documented provenance decision.

Raw benchmark runs default to ignored `artifacts/` paths. Commit result summaries
under this directory only after checking that they do not include private voice
material, bulky generated audio, non-commercial artifacts that should not ship,
or host-specific secrets.
