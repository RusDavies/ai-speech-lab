# Project Knowledge

AI Speech Lab is a research-heavy open source TTS project. Use this entrypoint before
substantive product, research, architecture, benchmark, or implementation work.

Load policy:

- Read `knowledge/index.md` next.
- Load only the linked knowledge page relevant to the current task.
- Keep source-grounded findings in the knowledge pages and cite the original
  paper, repository, dataset, command, artifact, or discussion.
- Keep private planning or operational notes out of this product repository.
